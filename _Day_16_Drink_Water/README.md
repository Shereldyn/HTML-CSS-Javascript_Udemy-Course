# Day 16 Drink Water

## **Description of project**

- In this project, we're going to track glasses/cups of water as we add them to a jar.
- The jar will dynamically reveal the percentage of how much water is in the jar and how much space is left.
- When we click on any of the glasses, that glass will be highlighted as the jar is filled by that same amount.
- We will be using CSS to style the cups and jar, and add some javascript functionality to them.
- This is nice project to work on manipulating the DOM, and do a little bit of calculation.
